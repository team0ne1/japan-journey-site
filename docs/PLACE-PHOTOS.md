# 地点照片：全地点静态配图

2026-09-12 · 当前仅完成本地构建与预览，未推送或部署线上。

## 覆盖范围

61 个既有 PLACES 地点加上可选鸭川区域，共 62 个地点均有照片。每日行程、酒店、机场、车站、行李寄存点、备选景点卡片均按地点 ID 显示照片。照片不改变路线、时段、预算或稳定评论 ID。

`dist/place-images.js` 保存图片与来源元数据；`dist/place-photos.js` 渲染缩略图、署名和大图。`dist/photos/thumbs/` 提供较小缩略图，合计约 1.8 MiB；完整照片合计约 11.1 MiB。缩略图延迟加载，点击时才请求完整图片。

## 来源与画面说明

56 张来自 Wikimedia Commons，保留作者、原始来源与各自的 CC 许可或公有领域声明。6 张来自酒店、商店或政府官网，标记为“官网图片 · 版权所有”；它们不被当作开放许可图片，记录来源不等于取得转载授权。具体清单见 [PHOTO-SOURCES.md](PHOTO-SOURCES.md)。

目视核对地点，并排除其他城市的同名地点。必要时在卡片中说明图片的实际范围：若王子区域使用哲学小道景观参考；花火会场使用平日公园照片，不表示2026年花火实况；酒店照片说明实际拍摄区域。季节、天气和旅行当天可能不同。

## 交互与维护

- 所有图片由本站静态资源加载，不在用户访问时抓取搜索结果，不需要 API Key、数据库或新的 Worker 接口。
- 点击照片打开原比例大图，显示作者、来源、许可及画面说明；Escape 可关闭。
- 异常加载失败时显示图片搜索入口，不影响行程与评论。
- 构建会检查所有地点的图片、缩略图、来源信息及 JPEG 文件，缺图即报错。
- 新地点需要同时补充照片清单和资源。用户界面没有上传、更换照片或编辑行程入口。

未来 Markdown 行程可引用独立图片清单；本次没有接入解析器、个人行程副本或合并功能。
